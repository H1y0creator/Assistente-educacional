# Contribuindo

Obrigado pelo interesse em contribuir com o Digi 2.0.

## Como contribuir

1. Abra uma issue descrevendo o problema ou a melhoria.
2. Para mudanças maiores, discuta a proposta antes de implementar.
3. Crie uma branch a partir da branch principal.
4. Faça alterações pequenas e com objetivo claro.
5. Teste os fluxos afetados e descreva os testes realizados no pull request.

## Padrão de commits

Prefira mensagens curtas e objetivas, por exemplo:

- `feat: adiciona classificação de intenção`
- `fix: corrige validação do webhook`
- `docs: atualiza instruções de instalação`
- `refactor: organiza integração com WhatsApp`

## Cuidados

- Nunca inclua arquivos `.env`, credenciais, dados reais de estudantes ou backups.
- Não publique tokens em prints, logs, workflows ou exemplos.
- Atualize a documentação quando alterar a arquitetura ou a configuração.
