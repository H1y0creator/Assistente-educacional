# Segurança

Não reporte vulnerabilidades publicamente com tokens, dados pessoais ou detalhes exploráveis.

- Não envie segredos em issues ou pull requests.
- Para comunicar uma vulnerabilidade, contate privadamente os mantenedores do repositório.
- Se uma credencial for exposta, revogue-a imediatamente e gere uma nova.
- Não exponha PostgreSQL ou Redis diretamente à internet.
- Proteja a interface n8n e os endpoints públicos com autenticação, HTTPS e controles de acesso.
- Faça backups protegidos e teste periodicamente a restauração.
